Relay's workspace has moved to React and Framer Motion, with a cinematic dark layout.

- A recessed conversation stage, quieter sidebar, refined typography and responsive composer.
- Animated relay artwork, short page transitions and clearer focus and hover feedback, with reduced-motion support.
- React chat history, live messages, question choices, attachments, queues, subagents and side panels.
- React Usage, Rules, Skills, Settings and Themes screens; saved theme preferences remain compatible.
- Starter actions fill an empty composer without sending or replacing an existing draft.

Validation: automated behavior tests, Electron workspace checks, React UI checks at 1280×800 and 860×760, draft protection and reduced-motion checks, and packaged-source integrity.

This is a substantial renderer migration. The automated UI checks use mock provider responses; live sign-in, provider execution, browser navigation and update installation have not all been exercised for this release.
